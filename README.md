# AI-Islamic-Research-Writer

## وصف المشروع
تطوير منصّة ويب بحثية شرعية متقدمة تعتمد على الذكاء الاصطناعي، تهدف إلى مساعدة طلاب العلم والباحثين في إعداد بحوث شرعية موثوقة، منظمة، وقابلة للاستخدام الأكاديمي، مع الالتزام بالمنهج العلمي المعتمد في الاستدلال الشرعي.

## البدء السريع
يمكن تشغيل النسخة الأولية مباشرة عبر فتح ملف `index.html` في المتصفح، أو باستخدام خادم محلي بسيط:

```bash
python -m http.server 8000
```

بعد ذلك افتح الرابط: `http://localhost:8000`.

## هدف المشروع
إنشاء **AI Islamic Research Writer** يقوم بـ:

- تحليل المسائل الشرعية تحليلًا علميًا دقيقًا.
- استخراج الأدلة من مصادرها الأصلية.
- عرض أقوال العلماء مع بيان الخلاف المعتبر.
- إنتاج مخرجات بحثية منظمة وفق المعايير الأكاديمية.

## النطاق الوظيفي (Scope)
- إدخال موضوع البحث أو السؤال الشرعي.
- اختيار المستوى العلمي (بكالوريوس – ماجستير – دكتوراه).
- توليد بحث شرعي منظم يشمل:
  - مقدمة.
  - أدلة من القرآن والسنة.
  - أقوال العلماء.
  - مناقشة علمية.
  - خاتمة.
  - مراجع.
- دعم التصدير إلى Word وPDF (RTL – عربي).

## المنهجية الشرعية
- الالتزام بمنهج أهل السنة والجماعة.
- الاعتماد على:
  - القرآن الكريم.
  - السنة النبوية الصحيحة.
  - الإجماع.
  - القياس عند الحاجة.
- احترام الخلاف الفقهي المعتبر.
- عدم إصدار فتاوى في القضايا المعاصرة الحساسة.

## الخصائص التقنية
- دعم كامل للغة العربية (RTL).
- واجهة أكاديمية بسيطة.
- بنية قابلة للتوسّع.
- جاهزية للربط مع المكتبات الشرعية الرقمية.
- قابلية التكامل عبر API.

## الضوابط والأخلاقيات
- هذه المنصّة أداة مساعدة للبحث العلمي ولا تغني عن الرجوع إلى العلماء المختصين.
- الالتزام بالأمانة العلمية.
- منع المحتوى غير المنهجي أو المتطرّف.
- توضيح أن النتائج لأغراض بحثية وتعليمية.

## الرؤية المستقبلية
- إضافة نظام حسابات المستخدمين.
- ربط مباشر بالمكتبات الشرعية.
- دعم لغات إضافية.
- مراجعة بشرية للبحوث.

## النتيجة المتوقعة
مشروع مفتوح المصدر يقدّم مساعدًا ذكيًا للبحث الشرعي بمستوى أكاديمي موثوق يخدم طلاب العلم والمؤسسات التعليمية.
